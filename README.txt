# Fraud Detection Using Data Analysis

## Project Overview
This project analyzes transaction data to identify patterns and behaviors associated with fraudulent transactions.

## Dataset
The dataset contains 50,119 transaction records with information such as:
- Transaction Amount
- Transaction Type
- Time of Transaction
- Device Used
- Location
- Previous Fraudulent Transactions
- Account Age
- Number of Transactions in Last 24 Hours
- Payment Method
- Fraudulent

## Analysis Performed
- Transaction Amount vs Fraud
- Time of Transaction vs Fraud
- Device Changes vs Fraud
- Account Age vs Fraud
- Transaction Frequency vs Fraud
- Outlier Detection
- Statistical Analysis
- Data Visualization

## Findings
The analysis helps identify unusual transaction patterns and behaviors that may indicate fraudulent activity. Statistical methods and visualizations were used to understand the differences between fraudulent and non-fraudulent transactions.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
